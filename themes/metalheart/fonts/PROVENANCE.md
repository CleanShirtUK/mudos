# Metalheart bundled font provenance

- **Oxanium Variable** — SIL Open Font License 1.1. Upstream Google Fonts:
  `https://github.com/google/fonts/tree/main/ofl/oxanium`. The full license is
  in `OXANIUM-OFL.txt`.
- **Share Tech Mono Regular** — SIL Open Font License 1.1. Upstream Google
  Fonts: `https://github.com/google/fonts/tree/main/ofl/sharetechmono`. The full
  license is in `SHARE-TECH-MONO-OFL.txt`.
- **JetBrainsMono Nerd Font Regular** — used only for fallback semantic icon
  glyphs. License text is included in `NERD-FONTS-LICENSE.txt`.
- **Config Glyphs** — bundled controller-symbol face with its upstream
  provenance statement in `CONTROLLER-ICONS-FONT-PROVENANCE.txt`, vendored from
  `https://github.com/SamarthMP/controller-icons-font`. The upstream README
  describes it as free/open-source but gives no specific SPDX license; this
  existing Mudos controller asset is retained for compatibility.
  Ordinary text uses the OFL-licensed Share Tech Mono and Oxanium faces above.

The bundled typefaces are data assets only; no proprietary historic font is
used.
