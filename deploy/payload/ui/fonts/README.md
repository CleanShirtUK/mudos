# Bundled fonts

`JetBrainsMonoNLNerdFont-*.ttf` are JetBrains Mono Nerd Font no-ligature
variants. They are loaded by `Typography.qml` with `FontLoader`; runtime family
names are taken from `FontLoader.name`. Licensing notices are kept beside the
font files.

`Config-Glyphs.otf` is the controller-icons-font asset from
`SamarthMP/controller-icons-font`. The upstream README calls it “free and
open-source”; no specific licence is asserted here because upstream does not
provide one.
